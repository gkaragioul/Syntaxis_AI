# SyntaxisAI User Guide

## Introduction
Welcome to SyntaxisAI, an intelligent invoice processing system that automates the extraction and management of invoice data. This guide will help you get started and make the most of our platform.

## Getting Started

### Account Setup
1. Visit [https://app.syntaxisai.com/register](https://app.syntaxisai.com/register)
2. Fill in your company details and create an account
3. Verify your email address
4. Complete your profile setup
5. Choose your subscription plan

### System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- PDF, PNG, or JPEG invoice files
- Minimum screen resolution: 1280x720

## Core Features

### Dashboard
The dashboard provides an overview of your invoice processing activities:
- Recent invoices
- Processing status
- Error reports
- System notifications
- Quick actions

### Invoice Processing

#### Single Invoice Upload
1. Click "Upload Invoice" in the dashboard
2. Select your invoice file (PDF, PNG, or JPEG)
3. Choose processing options:
   - Priority level
   - Template selection
   - Extraction rules
4. Click "Process"
5. Monitor processing status
6. Review and verify extracted data

#### Batch Processing
1. Click "Batch Upload" in the dashboard
2. Select multiple invoice files
3. Configure batch options:
   - Processing priority
   - Template selection
   - Concurrency settings
   - Notification preferences
4. Start processing
5. Monitor batch progress
6. Review results
